# Imágenes de Aplicaciones Móviles

## Recomendaciones para imágenes de apps móviles:

### Dimensiones recomendadas:
- **Capturas de pantalla**: 375x812px (iPhone) o 360x640px (Android)
- **Mockups**: 300x600px (proporción 1:2)
- **Formato**: PNG con fondo transparente o JPG

### Tipos de imágenes que funcionan bien:
1. **Screenshots reales** de la aplicación
2. **Mockups profesionales** con dispositivos
3. **Composiciones** mostrando múltiples pantallas
4. **Videos convertidos** a GIF (opcional)

### Ejemplos de nombres de archivo:
- `agritrack-mobile.png`
- `health-app-mockup.jpg`
- `ecommerce-app-screens.png`

### Notas importantes:
- Las imágenes se muestran con `object-contain` para mantener proporciones
- Se añade un fondo sutil para apps con fondos transparentes
- El diseño es responsive y se adapta a diferentes tamaños
